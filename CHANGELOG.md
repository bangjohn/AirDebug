# Changelog

## 1.0.1 - 2026-10-31

- Fix: text was unreadable (white on white) when Windows uses dark mode
- New: light and dark theme that follows the Windows app mode automatically, also while AirDebug is running
- Clearer checkboxes in both themes

## 1.0.0 - 2026-10-31

First release.

- Pair Android 11+ phones over Wi-Fi with a QR code or a 6-digit pairing code, without Android Studio
- Automatic discovery of phones via mDNS
- Auto-reconnect of remembered phones, following port/IP changes
- System tray icon with status, notifications and quick actions
- Start with Windows (optional), start minimized
- USB → Wi-Fi (`adb tcpip`) for Android 10 and older
- Downloads Google's Platform-Tools automatically when adb is missing
- English and Bahasa Indonesia UI
